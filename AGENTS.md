# Карман

Личный заметочник со свободным холстом в Telegram Mini Apps.

## Требования и этап работы

Перед изменением поведения, архитектуры или плана работ прочитай [спецификацию](docs/specs/karman/spec.md). В ней находятся согласованные требования, открытые вопросы и критерии проверки.

Спецификация согласована. Изменение согласованных требований обсуждай с пользователем и записывай в спецификацию. Реализация идёт по опубликованным задачам.

## Рабочий процесс

- Следуй маршруту: настройка навыков → grilling → согласованная спецификация → задачи → реализация с проверками и ревью.
- Источник выбранного пользователем процесса: `C:/dev/temp/skills`. Навыки читай по точным путям из текущего каталога доступных навыков; при отсутствии регистрации проверяй конкретный файл в указанном источнике.
- Требования храни в `docs/specs/<feature>/spec.md`. Текущая спецификация продукта — `docs/specs/karman/spec.md`.
- Задачи планируются в GitHub Issues этого репозитория. Репозиторий публичный: всё, что попадает в issues, видно всем.
- В ходе обсуждения обновляй спецификацию принятыми решениями; предложения и нерешённые вопросы обозначай явно.

## Границы технических решений

В качестве основы выбран Telegram Serverless. Доступ к нему пока не получен (лист ожидания), поэтому первая версия разрабатывается в браузере с временным хранилищем за слоем API заметок. Проверяй доступность платформы и её SDK до реализации интеграции. Изменение платформы согласуй с пользователем.

Продукт выпускается этапами; состав первой версии описан в спецификации. Полный оффлайн, включая повторное открытие, — требование следующего этапа, не первой версии. Данные первой версии проектируй так, чтобы оффлайн и синхронизацию можно было добавить без переделки формата. Перед реализацией оффлайна нужен прототип на Android, iPhone и Telegram Desktop для Windows. Результаты обычного браузера не доказывают поведение Telegram.

Основа холста — Excalidraw на React. Код на TypeScript: имена, комментарии и коммиты на английском, документация на русском. Интерфейс на русском и английском; детали — в спецификации. Механизм локального хранения и протокол синхронизации пока не выбраны.
