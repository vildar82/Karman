# Карман

Заметочник в Telegram Mini Apps.

Статус: обсуждение продукта. Спецификация, задачи и реализация ещё не подготовлены.

## Исходные требования

- Интерфейс Mini App на HTML/JavaScript; React рассматривается как вариант.
- Telegram Serverless для создания, чтения, изменения и удаления заметок.
- Постоянная SQLite-база платформы с таблицей `Notes`: `Id`, `UserId`, `Title`, `Content`, `CreatedAt`, `UpdatedAt`.
- Авторизация через Telegram без отдельного логина.

Согласно документации Telegram Serverless, платформа размещает backend, базу и собранные файлы интерфейса. Отдельный хостинг в этой схеме не требуется. Доступность Serverless для выбранного бота ещё предстоит проверить в BotFather.

## Порядок работы

1. Настроить правила проекта, место хранения спецификации и трекер задач через `setup-matt-pocock-skills`.
2. Пройти `grilling` / `grill-with-docs`: определить пользу продукта, сценарии, границы первой версии и решения.
3. Подготовить и согласовать спецификацию через `to-spec`.
4. Разбить спецификацию на проверяемые задачи с зависимостями через `to-tickets`.
5. Реализовать согласованные задачи через `implement-spec` / `implement`, с подходящими проверками и ревью.

Исходники навыков: `C:/dev/temp/skills`. Выбор технологий и детали поведения уточняются до реализации.
