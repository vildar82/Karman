# Карман

Личный заметочник со свободным холстом: текст, рисунки и схемы. Целевая платформа — Telegram Mini Apps.

Спецификация согласована: [требования и этапы](docs/specs/karman/spec.md), [задачи в GitHub](https://github.com/vildar82/Karman/issues). Сейчас разрабатывается браузерная версия до получения доступа к Telegram Serverless. Готов каркас: пустой экран «Мои заметки», русский и английский интерфейс, инфраструктура проверок. Создание и сохранение заметок — следующая задача #3.

## Локальный запуск

Нужен Node.js 22.12+, 24 или 26+. В CI используется Node.js 24.

```powershell
npm ci
npm run dev
```

Приложение откроется по адресу http://127.0.0.1:5173. Для просмотра выполните переход в браузере; Vite не открывает окно автоматически.

## Проверки

Перед первым запуском сквозных тестов установите Chromium:

```powershell
npx playwright install chromium
```

Все проверки одной командой:

```powershell
npm run check
```

Отдельные команды:

| Команда | Назначение |
| --- | --- |
| `npm run typecheck` | Проверка типов TypeScript, включая тесты и конфигурации |
| `npm run build` | Продакшен-сборка в `dist/` |
| `npm test` | Модульные тесты Vitest: выбор языка, склонения и даты |
| `npm run test:e2e` | Сквозные тесты Playwright в Chromium; сервер Vite запускается автоматически |
| `npm run preview` | Просмотр собранного приложения |

GitHub Actions запускает `npm run check` на push и pull request. При падении браузерного теста сохраняет скриншот и трассировку в артефакт `playwright-results`. Локальные результаты находятся в `test-results/`.

## Структура

- `src/App.tsx` — экран списка заметок.
- `src/i18n.ts` — типизированные словари `ru` и `en`, выбор языка, склонения через `Intl.PluralRules` и даты через `Intl.DateTimeFormat`.
- `src/main.tsx` — вход в приложение. Язык берётся из `Telegram.WebApp.initDataUnsafe.user.language_code`, если объект уже доступен, иначе из языка браузера; `ru*` означает русский, остальные языки — английский.
- `src/telegram.d.ts` — минимальный тип для чтения языка из окружения. Подключение SDK и авторизация Telegram ещё не реализованы; `initDataUnsafe` не используется как подтверждение личности.
- `e2e/` — проверки пустого экрана, локализации и мобильного размера окна в браузере.
- `assets/brand/` — брендовые материалы.

Холст Excalidraw и слой API заметок добавляются следующими задачами. Интеграция с Telegram и Serverless начнётся после получения доступа. Оффлайн и синхронизация относятся к следующим этапам. Браузерные тесты не подтверждают работу в клиентах Telegram.
